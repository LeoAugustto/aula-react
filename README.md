# Aula React

Projeto criado para a aula de React com Vite, React Router DOM e JSON Server.

## Recursos

- Listagem de usuarios
- Cadastro de usuarios
- Navegacao entre paginas
- API fake com JSON Server

## Como rodar

Instale as dependencias:

```bash
npm install
```

Inicie a API fake:

```bash
npm run server
```

Em outro terminal, inicie o React:

```bash
npm run dev
```

Acesse:

```text
http://localhost:5173
```

A API fica em:

```text
http://localhost:3001/users
```
